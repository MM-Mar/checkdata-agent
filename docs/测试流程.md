## 6. 故障排查

| 现象 | 可能原因 | 解决 |
|---|---|---|
| SchemaStatsTest 连接失败 | MySQL 未启动 / 密码错误 | `Test-NetConnection 127.0.0.1 -Port 3306` |
| ExplainPrecheckTest 超时 | 大表未造数 / 造数中途失败 | 检查 `exp2_big_table` 是否存在且有 490w+ 行 |
| 实验一出现 IndexOutOfBounds | JSqlParser 版本不匹配 | 确认 pom.xml 中 JSqlParser 为 5.1 |
| DataScopeRewriterTest EXISTS 失败 | 老代码未修 | 确认 `DataScopeRewriter.java` 中有 `visit(ExistsExpression)` |
| mvn test 编译失败 | target/ 缓存脏 | `mvn clean test-compile` |
